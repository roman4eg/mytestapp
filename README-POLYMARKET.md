# Polymarket Event Viewer

Веб-додаток для перегляду доступних подій та ставок на платформі Polymarket через API.

## Особливості

- 📊 Перегляд активних та закритих подій на Polymarket
- 🎯 Детальна інформація про кожну подію та доступні ринки
- 🔍 Фільтрація за статусом (активні/закриті/всі)
- 📈 Статистика по подіям та ринкам
- 🎨 Сучасний та зручний інтерфейс
- 📱 Адаптивний дизайн для мобільних пристроїв
- 🌐 Працює локально без необхідності сервера

## Як використовувати

### ⚠️ ВАЖЛИВО: CORS Обмеження

Через CORS політику браузерів, ви **НЕ МОЖЕТЕ** просто відкрити HTML файл безпосередньо. Потрібно використовувати один з проксі-серверів нижче.

### Метод 1: Python Flask Proxy Server (Рекомендовано)

```bash
# 1. Встановіть залежності
pip install -r requirements.txt

# 2. Запустіть сервер
python proxy-server.py

# 3. Відкрийте в браузері
# http://localhost:5000
```

Сервер автоматично відкриє сторінку та проксує запити до Polymarket API.

### Метод 2: Node.js Express Proxy Server

```bash
# 1. Встановіть залежності
npm install

# 2. Запустіть сервер
npm start

# 3. Відкрийте в браузері
# http://localhost:5000
```

### Метод 3: Використання Live Server (VS Code)

Якщо ви використовуєте VS Code та хочете швидко протестувати:

1. Встановіть розширення "Live Server"
2. Клацніть правою кнопкою миші на `polymarket-viewer.html`
3. Виберіть "Open with Live Server"

**Увага:** Цей метод НЕ вирішує CORS проблему! Вам все одно потрібен проксі-сервер.

## Функціонал

### Фільтри

- **Статус**: Активні події, закриті події або всі події
- **Сортування**: За новизною (найновіші/найстаріші)
- **Кількість**: Скільки подій завантажувати (12/24/50/100)

### Інформація про події

Для кожної події відображається:

- Назва та опис події
- Зображення (якщо доступне)
- Кількість ринків (загальна та активні)
- Статус події (активна/закрита)
- Теги/категорії
- Доступні ринки для ставок
- Можливі результати для кожного ринку

### Детальний перегляд

Клацніть на будь-якій події для перегляду:

- Повної інформації про подію
- Всіх доступних ринків
- Дат початку та закінчення
- Прямого посилання на Polymarket

### Статистика

На головній сторінці відображається:

- Загальна кількість завантажених подій
- Кількість активних подій
- Загальна кількість ринків

## Технічні деталі

### API Endpoints

Додаток використовує офіційний Polymarket Gamma API:

- **Base URL**: `https://gamma-api.polymarket.com`
- **Endpoint**: `/events`
- **Документація**: [docs.polymarket.com](https://docs.polymarket.com)

### Параметри запитів

- `limit`: Кількість подій для завантаження
- `offset`: Зміщення для пагінації
- `order`: Поле для сортування (id)
- `ascending`: Напрямок сортування (true/false)
- `closed`: Фільтр закритих подій
- `active`: Фільтр активних подій
- `archived`: Фільтр архівних подій

### Технології

- HTML5
- CSS3 (з градієнтами та анімаціями)
- Vanilla JavaScript (ES6+)
- Fetch API для HTTP запитів
- Адаптивний дизайн (CSS Grid, Flexbox)

## Вирішення проблем

### CORS помилки (Failed to fetch)

**Проблема:** При відкритті файлу безпосередньо отримуєте помилку:
```
Access to fetch at 'https://gamma-api.polymarket.com/events' from origin 'null'
has been blocked by CORS policy: No 'Access-Control-Allow-Origin' header is present
```

**Рішення:** Це очікувана поведінка! Ви ПОВИННІ використовувати один з проксі-серверів:

1. **Python версія (найпростіше):**
   ```bash
   pip install -r requirements.txt
   python proxy-server.py
   ```
   Відкрийте http://localhost:5000

2. **Node.js версія:**
   ```bash
   npm install
   npm start
   ```
   Відкрийте http://localhost:5000

### Події не завантажуються

1. Перевірте, що проксі-сервер запущений і працює
2. Переконайтесь, що порт 5000 не зайнятий іншим процесом
3. Перевірте підключення до інтернету
4. Відкрийте http://localhost:5000/health для перевірки статусу сервера
5. Відкрийте консоль браузера (F12) для перегляду детальних помилок

### Порт 5000 вже зайнятий

Якщо порт 5000 вже використовується, змініть PORT у файлах серверів:

**proxy-server.py:**
```python
app.run(host='0.0.0.0', port=8080, debug=True)  # Змініть 5000 на 8080
```

**proxy-server.js:**
```javascript
const PORT = 8080;  // Змініть 5000 на 8080
```

### Зображення не відображаються

Деякі зображення можуть не завантажуватись через CORS політику або невалідні URL. Це нормально і не впливає на функціональність додатку.
