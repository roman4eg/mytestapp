# Polymarket Event Viewer

Веб-додаток для перегляду доступних подій та ставок на платформі Polymarket через API.

## Особливості

- 📊 Перегляд активних та закритих подій на Polymarket
- 🎯 Детальна інформація про кожну подію та доступні ринки
- 🔍 Фільтрація за статусом (активні/закриті/всі)
- 📈 Статистика по подіям та ринкам
- 🎨 Сучасний та зручний інтерфейс
- 📱 Адаптивний дизайн для мобільних пристроїв
- 🌐 Працює локально без необхідності сервера

## Як використовувати

### Метод 1: Відкрити безпосередньо у браузері

1. Знайдіть файл `polymarket-viewer.html` у вашому проекті
2. Двічі клацніть на ньому або клацніть правою кнопкою миші → Відкрити за допомогою → Ваш браузер
3. Файл автоматично завантажить події при відкритті

### Метод 2: Використання Live Server (рекомендовано)

Якщо ви використовуєте VS Code:

1. Встановіть розширення "Live Server"
2. Клацніть правою кнопкою миші на `polymarket-viewer.html`
3. Виберіть "Open with Live Server"

### Метод 3: Використання Python HTTP Server

```bash
# Python 3
python -m http.server 8000

# Потім відкрийте в браузері:
# http://localhost:8000/polymarket-viewer.html
```

## Функціонал

### Фільтри

- **Статус**: Активні події, закриті події або всі події
- **Сортування**: За новизною (найновіші/найстаріші)
- **Кількість**: Скільки подій завантажувати (12/24/50/100)

### Інформація про події

Для кожної події відображається:

- Назва та опис події
- Зображення (якщо доступне)
- Кількість ринків (загальна та активні)
- Статус події (активна/закрита)
- Теги/категорії
- Доступні ринки для ставок
- Можливі результати для кожного ринку

### Детальний перегляд

Клацніть на будь-якій події для перегляду:

- Повної інформації про подію
- Всіх доступних ринків
- Дат початку та закінчення
- Прямого посилання на Polymarket

### Статистика

На головній сторінці відображається:

- Загальна кількість завантажених подій
- Кількість активних подій
- Загальна кількість ринків

## Технічні деталі

### API Endpoints

Додаток використовує офіційний Polymarket Gamma API:

- **Base URL**: `https://gamma-api.polymarket.com`
- **Endpoint**: `/events`
- **Документація**: [docs.polymarket.com](https://docs.polymarket.com)

### Параметри запитів

- `limit`: Кількість подій для завантаження
- `offset`: Зміщення для пагінації
- `order`: Поле для сортування (id)
- `ascending`: Напрямок сортування (true/false)
- `closed`: Фільтр закритих подій
- `active`: Фільтр активних подій
- `archived`: Фільтр архівних подій

### Технології

- HTML5
- CSS3 (з градієнтами та анімаціями)
- Vanilla JavaScript (ES6+)
- Fetch API для HTTP запитів
- Адаптивний дизайн (CSS Grid, Flexbox)

## Вирішення проблем

### Події не завантажуються

1. Перевірте підключення до інтернету
2. Переконайтесь, що API Polymarket доступний
3. Відкрийте консоль браузера (F12) для перегляду помилок

### CORS помилки

Якщо виникають CORS помилки, використовуйте один з методів:

1. Використовуйте Live Server або локальний HTTP сервер
2. Відкрийте Chrome з відключеним CORS (тільки для розробки):
   ```bash
   chrome.exe --user-data-dir="C:/Chrome dev session" --disable-web-security
   ```

### Зображення не відображаються

Деякі зображення можуть не завантажуватись через CORS політику або невалідні URL. Це нормально і не впливає на функціональність додатку.
